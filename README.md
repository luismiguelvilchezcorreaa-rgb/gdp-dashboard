# Health & Feelings A2 — GitHub Pages

## Publish
1. Open your GitHub repository.
2. Remove/replace the old site files.
3. Upload `index.html` and the `assets` folder to the repository root.
4. Commit the changes.
5. In Settings → Pages, choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
6. Open your GitHub Pages URL.

This package is fully static and does not require Node, npm, React, or a build step.
